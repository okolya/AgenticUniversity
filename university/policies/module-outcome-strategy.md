# Module Outcome Strategy Policy

## Owner

The appointed Dean owns the outcome strategy of a Course/Module. The Dean defines whether professional application and/or external certification are relevant, but does not prescribe a concrete product merely to create activity.

## Professional relevance first

Learning scope must serve the profession, an explicitly adopted external certification, or both. Do not teach technology breadth merely because it exists. Certification-only requirements become legitimate scope only when the certification has been intentionally adopted as an outcome.

## Product application

A Module may require or recommend real-world transfer after the internal examination. The Dean records the need for application in the Student Module plan and appoints suitable workers to investigate it with the Student. The appointed workers select an appropriate real context/project, define bounded scope, expected evidence, and return an Application Plan. The Dean does not name a mandatory product in advance unless the Student context itself makes that constraint explicit.

The returned Application Plan must be persisted in the private Student Module Enrollment so it cannot disappear from the educational process.

## External certification

A Module Contract may classify external certification as `required`, `recommended`, `none`, or `undecided`. When a relevant certification is known during Module design, preparation should normally be integrated into the Module rather than deferred to an unrelated later course.

If a certification is discovered later, the Dean evaluates overlap with professional outcomes:
- strong overlap: integrate preparation into the Module framework for future use and into the current Student plan where appropriate;
- partial overlap: use a bounded certification-preparation activity/bridge;
- weak overlap: propose a separate preparation Course only when it has justified value.

Certification preparation never replaces the University's independent competence verification.

## Examination is not necessarily enrollment completion

The Examiner owns the internal Module verdict. After `EXAM_PASSED`, the Student Module Enrollment may continue with application and/or certification activities. Dean owns progression and ultimately marks the Student's Module Enrollment completed when its individual plan is resolved. The public University Module remains active and is not closed.
