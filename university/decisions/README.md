# Architecture decisions

Architecture Decision Records document decisions that constrain the public
University core and its hosts.

This tree owns decisions about the public University core: academic contracts,
Skills, workflows, protocols, manifest, and host-facing core rules. Workspace
planning and private development decisions belong to the separate
`documentation` repository. Numbering is local to this decision tree.

Use the next available four-digit number for a new decision. Each record must
state the status, context, decision, consequences, and scope boundary.
