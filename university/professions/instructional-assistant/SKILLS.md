# Instructional Assistant baseline skills

- `review-learning-material` — inspect pedagogical coherence, vocabulary
  progression, prerequisites, instructions, and learner-facing clarity
- `issue-management` — search and manage approved correction issue metadata
- `approved-material-patch` — apply only an authorized material correction
- `correction-git` — prepare the bounded branch, commit, PR, and merge path
- `correction-checks` — run and report required correction checks

The Profession may read the relevant learning material, its declared outcome,
applicable learning-content policies, and the minimum scope needed for the
review. It does not gain authority to alter Student state, approve academic
scope, or certify technical correctness.
