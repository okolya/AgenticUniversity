# Module Examination and Student Enrollment Completion

The public University Module is never closed by this workflow. This workflow distinguishes the internal examination from completion of a particular Student's Module Enrollment.

## Phase A — Internal examination

Owner: appointed Examiner who satisfies Assessment Independence Policy.

1. Load Module Exit Contract / Success Criteria and applicable AI-use mode.
2. Independently verify the criteria; Lesson consumption alone is not mastery evidence.
3. Produce a Module-level academic verdict and supporting evidence.
4. Record evidence/verdict in the private Student workspace within Examiner authority.
5. Return the verdict to Dean. `EXAM_PASSED` means the Exit Contract is verified; it does not automatically mean the Student Module Enrollment is complete.

## Phase B — Post-examination outcome activities

Owner: Dean for progression; execution is delegated to appropriate appointed workers.

1. Dean loads the Student's Module plan and Module Outcome Strategy.
2. If professional application is required/recommended, Dean appoints suitable workers (normally Laboratory Specialist, with Lecturer/Teacher when subject support is needed) to investigate an appropriate real application together with the Student.
3. Those workers return a persisted Application Plan containing competencies transferred, chosen context, rationale, bounded scope, assigned workers, Student responsibility, expected evidence, and status. Dean does not impose a specific product by default.
4. If external certification is adopted, relevant workers assess readiness and return any bounded preparation plan. Preparation remains part of the Student's Module plan.
5. Activities execute and return evidence/status to the Student Module Enrollment. Universally useful educational findings may be promoted into public University materials/methods without publishing private Student state.

## Phase C — Complete the Student Module Enrollment

Owner: Dean.

Dean marks only the private Student Module Enrollment / Module Learning Plan as `COMPLETED` when its required learning, internal examination, and assigned application/certification activities are completed, waived, or formally resolved.

Never mark the public University Module `closed` or `completed` because a Student completed it.
