# Learning assessment

Owner: appointed Learning Analyst satisfying Assessment Independence Policy.

This reusable workflow covers entry diagnostics, prerequisite assessment, gap analysis, re-assessment, competency verification, and retention checks.

1. Receive an explicit assessment request with scope, criteria, purpose, and permitted Student context.
2. Inspect existing evidence only as needed.
3. Select bounded assessment Skills appropriate to the criteria.
4. Conduct the assessment independently from teaching/coaching of the same scope.
5. Record evidence, uncertainty, and criterion-level findings.
6. Return results to the requesting workflow/Worker.
7. Do not decide curriculum, placement, progression, schedule, or final Module examination outcome.
