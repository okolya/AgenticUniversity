# Learning assessment

Owner: appointed Learning Analyst satisfying Assessment Independence Policy.

This reusable workflow covers entry diagnostics, prerequisite assessment, gap analysis, re-assessment, competency verification, and retention checks.

Assessment-specific handoffs use `assessment-contracts.md`; Student-facing
delivery, feedback, and progress reporting use
`learning-interaction-contracts.md`.

1. Receive and validate a complete Dean Assessment Request Contract from
   `university/protocols/assessment-contracts.md`. If it is incomplete, return
   the handoff without creating or conducting an assessment.
2. Prepare the learner-facing diagnostic or assessment artifact under the
   relevant public Course/Module/pre-course structure.
3. Invoke the `Instructional Assistant` Profession for a complete pedagogical
   review before publication or delivery. The Assistant reviews clarity and
   learner coherence, not validity or scoring.
4. Apply or reject the Assistant findings as the authorized assessment owner,
   then perform a complete final control review of the artifact.
5. Inspect existing evidence only as needed.
6. Select bounded assessment Skills appropriate to the criteria.
7. Conduct the assessment independently from teaching/coaching of the same scope.
8. For executable assessment work, inspect and run the submitted artifact,
   check required cases, and perform the smallest focused understanding check.
9. Record observed behavior, uncertainty, and criterion-level findings.
10. Return the Contract 4 Evidence Handoff to the requesting workflow/Worker.
11. Do not decide curriculum, placement, progression, schedule, or final
    Module examination outcome.
