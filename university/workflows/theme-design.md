# Theme Design Workflow

Owner: appointed Lecturer assigned to the Theme.

Purpose: convert an approved Module Theme frame into a coherent teachable unit.

1. Lecturer loads Course direction, approved Module purpose and Success Criteria, Theme frame, permitted Student evidence, and current Module plan.
2. Lecturer defines the Theme learning outcome and proposes explicit Theme Success Criteria traceable to the Module criteria.
3. Lecturer identifies the concepts/skills that must be introduced and what may be omitted because it is already verified.
4. Lecturer creates a minimal Lesson sequence for the Theme. Lessons are learning steps, not arbitrary chunks of text.
5. Lecturer identifies where Teacher reinforcement and Laboratory Specialist practice are useful and requests those contributions without transferring Theme ownership.
6. Lecturer researches/curates existing high-quality materials before authoring replacements. New material is authored where external material is unsuitable, incomplete, inaccessible, outdated, or a custom explanation is educationally better.
7. Lecturer prepares only the near-term Lessons/materials needed to start the Theme; later Lesson detail remains adaptive.
8. If the Theme requires changing Module scope or outcomes, Lecturer proposes the change to Dean rather than modifying the Module silently.
