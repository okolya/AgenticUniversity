# Module Entry

Owner: appointed Dean of the Faculty until the Module is formally started.

1. Dean loads the Module Entry Contract, Exit Contract, broad competency areas, and hard dependencies. Detailed teaching material is not required for entry.
2. Dean compares the Entry Contract with permitted **verified** Student competency/evidence state, using `check-prerequisites` for mechanical comparison where useful.
3. Prior Module completion may count as evidence, but is not itself the universal prerequisite. The question is whether the Entry Contract is satisfied.
4. If evidence is missing, stale, contradictory, or uncertain, Dean requests an Entry Assessment from an appointed independent Learning Analyst.
5. Learning Analyst receives the exact Entry criteria and permitted Student context, conducts only the needed assessment, and returns evidence/findings. Learning Analyst does not decide placement.
6. Dean interprets verified evidence and confirms direct entry, a bounded bridge, or another Course-permitted placement decision with the Student.
7. Dean uses `module-planning` to agree initial coverage and a short schedule. Already verified competencies are not taught again merely because they appeared in an earlier Module.
8. Dean completes Stage B of `module-design.md` and assigns the first Theme to an appointed Lecturer.
9. Lecturer owns Theme design and near-term Lesson preparation; Teacher and Laboratory Specialist receive bounded reinforcement/practice assignments from that teaching frame.
10. Detailed learning material is created/curated just in time to move the Student from actual state toward the Exit Contract.
