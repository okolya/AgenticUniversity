# Module Entry

Owner: appointed Dean of the Faculty until the Module is formally started.

Entry decisions and Worker/Student handoffs use
`university/protocols/learning-interaction-contracts.md`; independent
assessment uses `assessment-contracts.md`.

1. Module Entry is available only after the Dean confirms Course Entry. The
   pre-course diagnostic/orientation layer is governed by
   `course-entry.md`; it is not a public Module and is not repeated here.
2. Dean loads the Module Entry Contract, Exit Contract, broad competency areas, and hard dependencies. Detailed teaching material is not required for entry.
3. Dean compares the Entry Contract with permitted **verified** Student competency/evidence state, using `check-prerequisites` for mechanical comparison where useful.
4. Prior Module completion may count as evidence, but is not itself the universal prerequisite. The question is whether the Entry Contract is satisfied.
5. If evidence is missing, stale, contradictory, or uncertain, Dean requests an Entry Assessment from an appointed independent Learning Analyst.
6. Learning Analyst receives the exact Entry criteria and permitted Student context, conducts only the needed assessment, and returns evidence/findings. Learning Analyst does not decide placement.
7. Dean interprets verified evidence and confirms direct entry, a bounded bridge, or another Course-permitted placement decision with the Student.
8. Dean uses `module-planning` to agree initial coverage and a short schedule. Already verified competencies are not taught again merely because they appeared in an earlier Module.
9. Dean completes Stage B of `module-design.md` and issues the bounded
   pre-entry teaching sequence for the Entry Contract or approved bridge target.
10. Dean assigns the first Theme to an appointed Lecturer and hands over the
    sequence, checkpoints, and stop condition.
11. Lecturer owns Lesson design and preparation inside that bounded sequence;
    Teacher and Laboratory Specialist receive bounded reinforcement/practice
    assignments from that teaching frame.
12. Detailed learning material is created/curated just in time to execute the
    Dean-approved sequence. When the Entry Contract is evidenced, the slots are
    exhausted, or the stop condition is reached, Lecturer returns the
    accumulated evidence and unresolved gaps to Dean. Lecturer does not extend
    the sequence or declare Module Entry independently.
13. Dean makes the next bounded decision from the accumulated evidence: confirm
    Module Entry and start the Module, issue a new bounded bridge sequence,
    request independent measurement, or change the permitted trajectory.
    Starting the Module is a Dean decision, not an automatic result of
    producing another Lesson.
