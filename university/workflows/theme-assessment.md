# Theme assessment

Owner: appointed Learning Analyst who satisfies Assessment Independence Policy.

1. Receive a complete Dean Assessment Request Contract when independent Theme
   measurement is needed. Formative Lesson evidence alone does not authorize
   an assessment call.
2. Load Theme Success Criteria and applicable AI-use mode.
3. Build the learner-facing assessment artifact under the relevant public
   Course/Module/pre-course structure.
4. Invoke the `Instructional Assistant` Profession for a complete pedagogical
   review before the artifact is published or delivered.
5. Apply or reject the Assistant findings as the authorized Learning Analyst,
   then perform a complete final control review.
6. Conduct the independent assessment against the approved criteria.
7. Produce criterion-level findings, supporting evidence, and a clear
   assessment result for the Theme scope.
8. Use `update-evidence` only within Learning Analyst authority to record
   verified evidence in the private Student workspace.
9. Return the evidence/result to the owning learning or placement workflow.
10. Learning Analyst does not redesign curriculum, alter enrollment, prescribe
   the next Module, or replace the Examiner's Module verdict.
