# Faculty entry

Owner: appointed Dean of the Faculty.

1. Dean receives the Student's goal and permitted Student context.
2. Dean presents the real Faculty/Course/Module structure that currently exists; do not invent missing curriculum.
3. Dean inspects verified prior competencies/evidence relevant to possible entry points.
4. If evidence is insufficient for a placement decision, Dean requests a bounded assessment from an appointed Learning Analyst and supplies the criteria to measure.
5. Learning Analyst returns evidence/findings only; Dean retains trajectory authority.
6. Dean decides the appropriate entry point and whether earlier Modules can be skipped or bridged.
7. Dean and Student agree the initial short planning horizon.
8. Dean creates/updates enrollment using `create-enrollment`.
