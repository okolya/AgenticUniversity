# Responsibility matrix

| Academic object / decision | Primary owner | Contributors / users | Must not do |
|---|---|---|---|
| University structure | Rector | Deans | Rector does not own Faculty teaching content by default |
| Faculty | Dean | Rector governs/appoints | Other Faculty workers do not redefine it |
| Course name/direction/competencies/Module framework | Dean | Lecturer, Lab Specialist, Learning Analyst, Examiner | Contributors do not silently mutate Course |
| Module purpose/Entry Contract/Exit Contract/competency areas | Dean | Lecturer, Lab Specialist, Learning Analyst, Examiner | Does not pre-author Themes/Lessons/materials |
| Student-specific Theme framework near Module entry | Dean | Lecturer, Student, verified evidence | Must serve the fixed Module contract; not a hidden full syllabus |
| Module placement/skip/bridge | Dean | Learning Analyst supplies evidence | Analyst does not choose trajectory |
| Student Module coverage plan | Dean + Student | specialists contribute estimates/needs | Not a pre-generated full Lesson archive |
| Theme academic design | Lecturer | Teacher, Lab Specialist | Lecturer does not change Module outcomes silently |
| Lesson introducing new material | Lecturer | Teacher/Lab may contribute | Not independent assessment |
| Reinforcement/remediation session | Teacher | Lecturer supplies outcome/gap | Teacher does not expand curriculum authority |
| Lab/practical activity | Laboratory Specialist | Lecturer supplies outcomes | Lab Specialist does not issue mastery verdict |
| Entry/prerequisite/gap/theme/retention measurement | Learning Analyst | Dean/Lecturer may request | Analyst does not teach or choose next path |
| Internal Module examination/verdict | Examiner | may use prior evidence | Examiner does not teach/remediate, choose application context, complete Student enrollment, or set next trajectory |
| Module outcome strategy (application/certification) | Dean | Lecturer, Lab Specialist, Learning Analyst, Examiner may advise | Dean does not force a concrete product by default |
| Post-exam application discovery/plan | Laboratory Specialist or other Dean-appointed suitable worker(s) + Student | Lecturer/Teacher as needed | Must return a persisted plan; does not alter Module contract silently |
| Certification readiness/preparation plan | Dean owns placement; suitable appointed specialists execute/advise | Learning Analyst may measure readiness | Do not teach unrelated certification breadth unless certification is adopted |
| Student Module Enrollment completion | Dean | Examiner verdict + activity evidence | Completes only private Student enrollment; never closes public Module |
| Learning materials | Owner of the learning activity authors/curates; Lecturer owns core Theme/Lesson material | Teacher creates support material; Lab creates lab material | Material creation does not grant curriculum authority |
| Course route adaptation | Dean | Student + verified evidence | No lower role silently changes Course/Module outcomes |
| Lesson-level adaptation | Lecturer | Teacher/Lab observations | Does not override Module frame |

## Canonical handoff

`Dean defines Module competency contract → at entry Dean adapts coverage → Lecturer takes Theme → Lecturer takes new-material Lesson → Teacher reinforces → Lab Specialist handles practice → Learning Analyst independently measures → Examiner issues internal Module verdict → assigned workers complete required application/certification activities → Dean completes the Student Module Enrollment and decides next trajectory.`

Skills execute bounded operations. Policies constrain authority. Workflows define the handoff. No Skill owns an academic object or verdict.
