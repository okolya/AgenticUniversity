## Deutsch

### Ziel

Sie verstehen und verwenden häufige Wendungen in drei Alltagssituationen: etwas erfragen, etwas kaufen/organisieren und ein Problem klären.

### Wendungen

Eine Wendung ist hier eine kurze sprachliche Form für einen bestimmten **Zweck**: Information bekommen, etwas organisieren oder ein Problem klären.

- Erfragen: *Entschuldigung, wo ist …? / Können Sie mir bitte helfen? / Ich möchte wissen, ob …*
- Organisieren: *Ich möchte … buchen. / Wie viel kostet …? / Passt Ihnen …?*
- Problem klären: *Ich habe ein Problem mit … / Das habe ich nicht verstanden. / Können Sie das bitte wiederholen?*

### Aufgabe 1 — Zuordnen

Ordnen Sie die Wendungen den Situationen **Information**, **Organisation** oder **Problem** zu. Schreiben Sie danach je eine eigene Variante.

### Aufgabe 2 — Nachweis

Schreiben Sie drei kurze Mini-Dialoge mit je 3–4 Sätzen: an einer Haltestelle, bei einem Termin und bei einem kleinen Problem mit einer Bestellung. Verwenden Sie in jedem Dialog mindestens zwei Wendungen aus der Liste.

### Was ist neu?

Thema 1–3 kontrollierten Satzformen. Dieser Slot verlangt zusätzlich, dass Sie funktionale Sprache im passenden sozialen Zweck abrufen, nicht nur einzelne Wörter übersetzen.

### Rückgabe

Die drei Mini-Dialoge und eine Markierung der verwendeten Wendungen.

### Herkunft des Materials

Wendungen, Dialoge und Aufgaben sind original für diesen Slot geschrieben.

### Lexik-Spiel — Match-3 (~5 Min.)

**Regeln:** 3 Leben. Paare Lemma ↔ Kurzbedeutung. Formativ.

Karten: Entschuldigung · Können Sie …? · Ich hätte gern … · Wie komme ich …? · Vielen Dank

Bei ≥2 Fehlern: Lemma als `weak` notieren (`lektionslexik-guide.md`).

Formativ. Siehe `lektionslexik-guide.md`.

## Українською

### Lektionslexik / Lexik-Spiel / Lexik-Schreiben

Цільові лексеми, гра й речення — у німецькій секції (`lektionslexik-guide.md`).

### Мета

Ви розумієте й уживаєте часті звороти у трьох побутових ситуаціях: запитати інформацію, щось організувати або купити, пояснити проблему.

### Свідчення

Перед завданням використайте цей список:

- **Information / інформація:** *Entschuldigung, wo ist …?*; *Können Sie mir bitte helfen?*
- **Organisation / організація:** *Ich möchte … buchen.*; *Wie viel kostet …?*
- **Problem / проблема:** *Ich habe ein Problem mit …*; *Können Sie das bitte wiederholen?*

Мета висловлювання — це те, навіщо ви говорите: отримати інформацію, організувати щось або пояснити проблему.

Напишіть три короткі мінідіалоги по 3–4 речення: на зупинці, під час домовленості про зустріч і під час невеликої проблеми із замовленням. У кожному діалозі використайте щонайменше два звороти зі списку.

### Нове свідчення

Після Тем 1–3 ви додаєте до правильних форм речення функціональну мову для відповідної побутової мети, а не лише переклад окремих слів.
