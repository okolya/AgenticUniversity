## Deutsch

### Ziel und neuer Nachweis

Nach dieser Lektion erklären Sie einen vertrauten Plan und begründen ihn. Sie zeigen außerdem mindestens eine erwartete **Folge** (was danach passieren kann). Neu ist die Verbindung von Plan, mindestens zwei Gründen und einer Folge; eine Liste von Vorhaben ohne Zusammenhang reicht nicht.

### Sprachmittel

- *Ich habe vor, … zu … / Ich möchte … / Mein Plan ist, dass …*
- *Der erste Grund ist … / Außerdem …*
- *Deshalb … / Dadurch kann ich … / Wenn …, dann …*

Nach *weil* steht das Verb am Ende: *Ich lerne weiter, weil ich im Alltag sicherer sprechen möchte.* Nach *deshalb* steht das Verb normalerweise an zweiter Stelle: *Ich möchte sicherer sprechen, deshalb übe ich jeden Tag.*

### Aufgabe

Lesen Sie den Plan:

> Im nächsten Monat möchte Samira einen Abendkurs besuchen. Sie will zweimal pro Woche lernen, weil sie bei der Arbeit mehr Gespräche auf Deutsch führen muss. Außerdem möchte sie neue Leute kennenlernen. Wenn sie regelmäßig übt, kann sie ihre Antworten schneller bilden. Deshalb plant sie am Wochenende eine kurze Wiederholung.

Markieren Sie:

1. den Plan;
2. zwei Gründe;
3. eine erwartete Folge;
4. ein Mittel, mit dem Samira den Plan umsetzen will.

Ein **Zeitraum** sagt, wann oder wie lange etwas passiert, zum Beispiel *im nächsten Monat* oder *in den nächsten drei Wochen*. Ein **Umsetzungsschritt** ist eine konkrete Handlung, die den Plan möglich macht. Formulieren Sie danach vier eigene Sätze nach diesem Gerüst: **Plan + Zeitraum → Grund 1 → Grund 2 mit außerdem → Folge mit deshalb → Umsetzungsschritt**. Verbinden Sie die Sätze mit *weil, außerdem* und *deshalb*.

### Nachweis

Erklären Sie einen realistischen Plan für die nächsten Wochen, zum Beispiel für Lernen, Arbeit, Gesundheit, Freizeit oder eine Reise. Schreiben Sie **90–110 Wörter**. Ihr Beitrag muss enthalten:

- den Plan und einen Zeitraum;
- zwei verschiedene Gründe;
- eine erwartete Folge;
- eine konkrete Handlung zur Umsetzung;
- mindestens einen Satz mit *weil* und einen mit *deshalb*.

Verwenden Sie keinen Übersetzer und keine generative KI für den ersten Nachweis. Markieren Sie eine unsichere Form mit `?`.

### Українською

Поясніть знайомий план, щонайменше дві різні причини та очікуваний наслідок. Напишіть 90–110 слів, використайте *weil* і *deshalb*, а також конкретну дію для реалізації плану.
