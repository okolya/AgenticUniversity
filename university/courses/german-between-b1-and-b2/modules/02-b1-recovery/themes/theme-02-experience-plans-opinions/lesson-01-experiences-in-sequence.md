## Deutsch

### Ziel und neuer Nachweis

Nach dieser Lektion erzählen Sie eine kurze persönliche oder erfundene Erfahrung in einer verständlichen zeitlichen Ordnung. Sie verwenden mindestens drei **Zeitmarker** (Wörter, die die Reihenfolge zeigen), zum Beispiel *zuerst, danach, später, schließlich*. Neu ist ein zusammenhängender Beitrag mit Anfang, Entwicklung und Ergebnis; einzelne ungeordnete Sätze reichen nicht.

### Sprachmittel

- **Anfang:** *Zuerst habe ich … / Am Anfang …*
- **Weiter:** *Danach … / Später … / Währenddessen …*
- **Ende:** *Am Ende … / Schließlich …*
- **Reaktion:** *Ich war überrascht, weil … / Für mich war es wichtig, dass …*

Beispiel: *Zuerst wollte ich nur einen kurzen Spaziergang machen. Danach habe ich eine neue Strecke ausprobiert. Am Ende habe ich einen kleinen See gefunden, deshalb bin ich länger geblieben.*

### Aufgabe

Ordnen Sie die fünf Ereignisse und erzählen Sie daraus eine kurze Geschichte. Ergänzen Sie mindestens drei Zeitmarker und einen Satz über Ihre Reaktion.

1. Ich habe den falschen Bus genommen.
2. Ich habe eine Person nach dem Weg gefragt.
3. Ich bin an einem unbekannten Ort ausgestiegen.
4. Ich bin trotzdem pünktlich angekommen.
5. Ich habe eine neue Strecke gelernt.

Sprechen Sie Ihre Geschichte laut oder schreiben Sie zuerst fünf bis sieben Sätze. Prüfen Sie danach: Ist die Reihenfolge für eine andere Person klar?

### Nachweis

Eine **Ausgangssituation** ist die Situation am Anfang; eine **Reaktion** ist, wie Sie sich fühlen oder was Sie danach denken. Wählen Sie ein eigenes vertrautes Thema, zum Beispiel einen ersten Arbeitstag, eine Reise, einen Kurs oder ein gelungenes Problem. Schreiben Sie **80–100 Wörter** oder nehmen Sie eine **60–90 Sekunden** lange eigene Sprachaufnahme auf. Ihr Beitrag muss enthalten:

- eine klare Ausgangssituation;
- mindestens drei Zeitmarker;
- ein Ergebnis;
- eine kurze Reaktion oder Bewertung.

Verwenden Sie keinen Übersetzer und keine generative KI für den ersten Nachweis. Im Text markieren Sie eine unsichere Stelle mit `?`; in einer Sprachaufnahme nennen Sie danach den Zeitstempel oder schreiben Sie die unsichere Form in einer kurzen Notiz auf.
