# Lektion 3 — Module-Checkpoint und Prüfungsübergabe / Урок 3 — Module checkpoint і передача на іспит

- **Kurs / Modul / Thema:** Між B1 та B2 / Modul 4 / Thema 3
- **Lektion:** 3 von 3 / 3 із 3
- **Kriterium:** Theme 3–4; Module Exit 4; formative Module checkpoint
- **Status:** `unpiloted` (blockiert die Durchführung nicht); pädagogisches Review abgeschlossen; per-Student confirmation bei der Durchführung
- **Arbeitsmodus:** `NO_AI` für den gebündelten Text
- **Planzeit:** 45–60 Minuten

## Deutsch

### Ziel und neuer Nachweis

Nach dieser Lektion schließen Sie den **formativen Module-Checkpoint** ab und bereiten die Übergabe an den Dekan vor. Neu ist das gebündelte Paket. Diese Lektion erklärt **nicht** Module completion, erteilt kein `EXAM_PASSED` und schreibt keinen Bereitschaftsbericht.

### Recycle-Spiel — Theme-Pack (vor dem Nachweis, ~5–8 Min.)

Formatives Sammelspiel (nicht Teil eines `NO_AI`-Nachweises, falls getrennt): Evidenzlage, Selbstbild, nächster Schritt, Einschränkung, attested. Match-3 oder Lücken-Duell. Fail → Teacher vocab gym vor dem Nachweis. Keine neue Pflicht-`Lektionslexik`, außer unten zusätzlich genannt.

**Optional:** ein Satz mit einem schwachen Lemma (formativ).

### Formativer Checkpoint (bündeln)

1. Legen Sie bei: Theme-1-Grenztext, Theme-2-Checkpoint (oder gleichwertige RW-Nachweise), Lektion-2-Selbstbild.  
2. Schreiben Sie 40–60 Wörter **Deckblatt** für den Dekan: was im Paket liegt; was nur `attested` ist; ein Satz Nicht-Ansprüche (kein B2, kein Module-Urteil durch Lecturer).

### Contract-Übergabe an den Dean (Skeleton)

Der Lecturer füllt bei Student-Durchlauf:

- formative Module-4-Checkpoint-Paket vorhanden: ja/nein;  
- Evidence classes: RW Themes 1–2 (+ frühere Module nach Lage); HS nur `attested`;  
- Empfehlung: Dean prüft Autorisierung des Examiners (`module-exit` Phase A) **oder** gezielte Rückkehr/Brücke;  
- Nicht-Ansprüche: kein Enrollment-`COMPLETED`, kein B2-Bereitschaftsbericht hier, kein HS-Messwert.

### Stop condition

Wenn das Paket den Dean erreicht, endet die formative Lecturer-Arbeit an Modul 4. Examiner startet nur nach Dean-Autorisierung. Learning Analyst misst hier nicht erneut, sofern der Dean keine neue Assessment Request stellt. Keine vierte Lektion.
