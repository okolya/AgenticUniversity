# Thema 2 — Integrierte Hören/Sprechen-Praxis / Тема 2 — Інтегрована практика Hören/Sprechen

- **Kurs / Modul:** Між B1 та B2 / Modul 3 — Praxis und Bereitschaftsprüfung
- **Status:** ahead-of-student `ready` (Dean 2026-10-18); drei Lektionen `unpiloted` (`unpiloted` blockiert die Durchführung nicht); evidence class nur `attested`; per-Student delivery confirmation erfolgt bei der Durchführung
- **Outcome:** Der Student hält verständliche Kommunikation in vertrauten Situationen aufrecht und schließt die vorgeschriebene Hör- und Sprechpraxis ab.

## Grenzen und Kriterien

Im Rahmen: kurze Hörinputs und Sprechbeiträge zu vertrauten Themen; Interaktion ohne Abhängigkeit von isolierten Satzmustern; vorgeschriebene Praxis. Ausgeschlossen: unabhängige Messung von Hören/Sprechen; B2-Flüssigkeit; freie Debatte; Wiederholung von Modul-2-Reparaturtheorie ohne neuen Transferkontext.

1. Einen kurzen Hörinput auf B1-Niveau für die vorgeschriebene Praxis bewältigen (*attested*).
2. Eine verständliche Sprechleistung in einer vertrauten Situation erzeugen (*attested*).
3. Die Interaktion ohne isolierte Satzmuster aufrechterhalten (*attested*).
4. Theme-Checkpoint: integrierte kurze Hör-/Sprechpraxis in einem neuen vertrauten Kontext (*attested*).

## Verbindung zum Module Exit Contract

Advances Module criteria 1 (Hören/Sprechen-Anteil) and 2. Evidence class is only `attested` per `COURSE.md`. Learning Analyst and Examiner do not measure these criteria.

Checkpoint: one integrated short Hör-/Sprechpraxis with attestation markers only. Stop when the prescribed practice is recorded. Attestation alone never shortens or skips Hör-/Sprechpraxis. No fourth Lesson is added.

## Українською

### Межі й критерії

Тема охоплює короткі аудіовходи й усні внески на знайомі теми; взаємодію без ізольованих шаблонів; обов’язкову практику. Незалежне вимірювання Hören/Sprechen, побіжність B2 і вільні дебати виключені.

1. Виконати короткий обов’язковий listening (*attested*).
2. Дати зрозумілий усний внесок у знайомій ситуації (*attested*).
3. Підтримувати взаємодію без ізольованих речових шаблонів (*attested*).
4. Чекпойнт Теми: інтегрована коротка практика Hören/Sprechen у новому знайомому контексті (*attested*).

### Карта Уроків

Рівно три слоти: обов’язкове слухання → обов’язкове говоріння → інтегрований чекпойнт. Attestation ніколи сама по собі не скорочує практику. Жоден слот не додається без нового рішення Декана.
