# Lektion 3 — Theme-Checkpoint: Überarbeitungszyklus / Урок 3 — Чекпойнт: цикл переробки

- **Kurs / Modul / Thema:** Між B1 та B2 / Modul 3 / Thema 3
- **Lektion:** 3 von 3 / 3 із 3
- **Kriterium:** Theme 4; Module Exit 4, teilweise 5
- **Status:** `unpiloted` (blockiert die Durchführung nicht); pädagogisches Review abgeschlossen; per-Student confirmation bei der Durchführung
- **Arbeitsmodus:** `NO_AI` für den ersten Versuch
- **Planzeit:** 45–60 Minuten

## Deutsch

### Ziel und neuer Nachweis

Nach dieser Lektion durchlaufen Sie **einen** vollständigen Zyklus: neue kurze Aufgabe → begrenztes Feedback → eine Überarbeitung → sichtbarer Vergleich. Neu ist der integrierte Zyklus; Lektion 1–2 werden nicht wiederholt.

### Neue Aufgabe (erste Fassung)

Schreiben Sie 60–80 Wörter an das Bibliotheksteam:

Sie hatten Raum B12 für Mittwoch 16:00 reserviert. Der Raum ist geschlossen. Bitten Sie um Raum B08 für drei Personen **oder** um eine Stornierungsbestätigung.

### Begrenztes Feedback (vorgesehen)

Kriterium: **alle Schlüsselinformationen nennen** (Anlass, Wunsch, Personenanzahl/Zeit).

Feedback:

1. Anlass (B12 / Mittwoch) ist vorhanden.
2. **Zielstelle:** die Personenanzahl oder die Uhrzeit fehlt beziehungsweise ist unklar.
3. Abschluss ist ausreichend.

### Überarbeitung

Erstellen Sie eine zweite Fassung. Ändern Sie nur die Zielstelle; markieren Sie sie mit `[geändert]`. Kein zweiter Feedback-Zyklus.

### Nachweis

1. erste Fassung;
2. Feedback-Zielstelle in einem Satz genannt;
3. zweite Fassung mit `[geändert]`;
4. kurzer Vergleich: was sich beim selben Kriterium verbessert hat.

### Stop condition

Wenn der Vergleich vorliegt, endet Thema 3. Keine vierte Lektion und kein offener Rewrite-Zyklus. Unabhängige Messung folgt erst nach Thema 4 über den Dean.

### Українською

Чекпойнт: нове коротке завдання → обмежений feedback → одна переробка → видиме порівняння. Без відкритого циклу правок.

### Походження матеріалу

Завдання й feedback оригінально написані для цього слота.
