# AI Engineering — Pre-course

## Purpose

The pre-course is the public entry and preparation layer before the Student
enters the AI Engineering Course. It refreshes context, measures Entry
Contract readiness, and closes only the bounded gaps approved by the Dean.

The pre-course is not Module 0, does not count as Course delivery, and does not
change the Course's stable Module architecture. Its evidence supports the
Dean's Course Entry and first Module placement decision.

## Lifecycle

```text
orientation → bounded bridge → independent diagnostic → Dean Course Entry decision
```

Pre-course material is created only for a known entry gap. The Lecturer works
inside a Dean-issued bounded sequence. The Learning Analyst measures
independently. The Dean decides whether the Student enters the Course, needs
another bounded bridge, or requires a different placement decision.
