# Python Foundations Bridge

This is a bounded pre-course bridge, not a Module 1 Theme. It prepares and
measures only the entry capabilities needed before Course/Module Entry.

## Artifacts

- `BRIDGE.md` — approved bridge frame and bounded criteria;
- `lesson-01-read-and-run-a-small-python-program.md` — first bridge Lesson;
- `lesson-02-validate-input-and-handle-errors.md` — second bridge Lesson;
- `assessment-python-entry-diagnostic.md` — independent diagnostic for the
  Learning Analyst.
- `assessment-course-entry-git-and-boundaries.md` — two-slot Course Entry
  diagnostic for Git and source/configuration/secrets boundaries.

The bridge is complete only when its approved evidence checkpoint is reached
or its bounded slots are exhausted. The Dean then decides the next placement;
the bridge does not open Module 1 automatically.
