# Урок 2. Перевіряємо форму та типи даних

## Мета уроку

Після уроку студент уміє перевірити JSON-об'єкт за явною схемою та повернути
помітну помилку замість мовчазної заміни.

## Новий результат і зв'язок

Lesson 2 споживає словник, прочитаний у Lesson 1, і додає валідацію. Він
покриває поля, типи та інваріант даних — основу для безпечної трансформації у
Lesson 3.

## Практичне завдання

У папці Theme 2 додай:

```python
def validate_service(service):
    ...
```

Функція має перевіряти:

- наявність `service`, `healthy`, `latency_ms`;
- `service` — `str`;
- `healthy` — саме `bool`;
- `latency_ms` — саме `int` і значення від `0` до `5000`.

Для відсутнього поля або діапазону підніми `ValueError`, для неправильного
типу — `TypeError`. Повідомлення має називати поле та порушене правило.
Функція не змінює вхідний словник.

Перевір правильний об'єкт, відсутнє поле, неправильний тип і значення `6000`.
У `read_service.py` викликай валідацію після читання JSON і до наступного
кроку.

## Мінімальна здача

Поверни шлях до файла, команду та короткі фактичні результати чотирьох
випадків. Одним реченням поясни різницю між відсутнім полем і неправильним
типом. Lecturer сам інспектує й запускає код.

## Критерії

- схема описана явно;
- кожне правило перевіряється;
- помилки розрізняються;
- вхідний об'єкт не змінюється;
- лише валідний об'єкт переходить до Lesson 3.
