# Урок 1. Читаємо структуровані дані

## Мета уроку

Після уроку студент уміє прочитати JSON-файл у Python і зберегти значення
рядків, цілих чисел та логічних значень без зміни їхнього типу.

## Нові слова

- **Структуровані дані** — дані, організовані за визначеною формою: полями,
  списками та вкладеними значеннями.
- **JSON** — текстовий формат для обміну структурованими даними.
- **Поле** — іменована частина об'єкта даних, наприклад `city`.
- **Тип даних** — спосіб, у який програма розуміє значення: текст, число або
  логічне значення.

## Приклад

Файл `reading.json`:

```json
{
  "city": "Lviv",
  "temperature_c": 22,
  "is_day": true
}
```

Після читання через `json.load()` Python отримує словник. Значення `"Lviv"`
є текстом, `22` — цілим числом, а `true` — логічним значенням `True`.
Кавички й написання логічних значень належать JSON; у Python результат має
свої правила запису.

## Практичне завдання

Створи папку та файли:

- `homeworks/ai-engineering/2026.09/module-01/theme-02/reading.json`;
- `homeworks/ai-engineering/2026.09/module-01/theme-02/read_reading.py`.

У `read_reading.py` прочитай JSON через стандартну бібліотеку `json`, дістань
поля `city`, `temperature_c` та `is_day` і виведи коротке повідомлення.
Виведення має використовувати прочитані значення, а не повторювати їх вручну
в коді.

Запусти:

```bash
python3 homeworks/ai-engineering/2026.09/module-01/theme-02/read_reading.py
```

Зміни одне значення у `reading.json`, запусти програму повторно та переконайся,
що результат змінився відповідно.

## Мінімальна здача

Поверни шлях до файлів, команду запуску, короткий результат до і після зміни
JSON та одним реченням поясни типи трьох прочитаних полів. Приймаючий
працівник перегляне та запустить код.

## Критерії уроку

- JSON читається програмою, а не копіюється у вихідний код;
- поля дістаються за назвами;
- типи значень не змінюються без причини;
- контрольна зміна файла відображається у результаті.
