# Урок 1. Читаємо структурований JSON-об'єкт

## Мета уроку

Після уроку студент уміє прочитати JSON-об'єкт і зберегти його поля та типи
для подальшої перевірки. Це новий structured-data контекст, а не повторення
Course Entry diagnostic.

## Новий результат і зв'язок

Цей Lesson покриває початок Theme outcome: визначення форми даних. Він готує
об'єкт для Lesson 2; валідація ще не виконується.

## Практичне завдання

Створи:

- `homeworks/ai-engineering/2026.09/module-01/theme-02/service.json`;
- `homeworks/ai-engineering/2026.09/module-01/theme-02/read_service.py`.

JSON має містити:

```json
{
  "service": "search-api",
  "healthy": true,
  "latency_ms": 120
}
```

Через стандартну бібліотеку `json` прочитай об'єкт, дістань усі три поля та
виведи їхні значення. Не копіюй значення вручну в Python-код. Перевір, що
`service` — текст, `healthy` — логічне значення, `latency_ms` — ціле число.

Зміни `latency_ms` у JSON, запусти програму повторно та перевір результат.

## Мінімальна здача

Поверни шляхи файлів, команду запуску та короткий результат до і після зміни
JSON. Приймаючий Lecturer перегляне й запустить код.

## Критерії

- JSON читається програмою;
- поля дістаються за назвами;
- типи не втрачаються;
- результат Lesson 1 можна передати у `validate_service()` з Lesson 2.
