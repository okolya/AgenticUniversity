# Урок 3. Відокремлюємо точку запуску від компонента

## Мета уроку

Після уроку студент уміє розмістити функції, які можна повторно
використовувати, в одному файлі, а
точку запуску — в іншому, не втрачаючи зрозумілий потік даних.

## Що вже потрібно знати

Потрібно вміти створювати функції з параметрами та результатом через `return`.

## Нові слова

- **Модуль** — Python-файл, який містить код, що можна використати з іншого
  файла.
- **Імпорт** — підключення коду модуля до іншого файла через `import`.
- **Точка запуску** — файл або функція, через які користувач запускає програму.
- **Компонент** — обмежена частина програми з визначеною відповідальністю та
  способом взаємодії з іншими частинами.

## Приклад межі

Файл `score_logic.py` може містити `classify_score()` та `format_report()`.
Файл `score_app.py` імпортує їх, читає введення та запускає `main()`. Логіка
оцінки не повинна залежати від того, чи дані прийшли з термінала.

```python
# score_app.py
from score_logic import classify_score, format_report


def main():
    score = int(input("Score: "))
    label = classify_score(score)
    print(format_report(score, label))


if __name__ == "__main__":
    main()
```

## Практичне завдання

Візьми робочу програму `score_report.py` з Уроку 1 і розділи її на два файли в
тій самій папці:

- `score_logic.py` — `parse_score`, `classify_score` і `format_report`;
- `score_app.py` — `main()`, введення, виклики функцій і друкування.

Запускай програму так:

```bash
python3 homeworks/ai-engineering/2026.09/module-01/theme-01/score_app.py
```

Перевір `80`, `55` і щонайменше один помилковий випадок. Переконайся, що
запуск із іншої поточної папки не ламає імпорт, якщо команда використовує
шлях до `score_app.py`.

## Мінімальна здача

Поверни шляхи двох файлів, команду запуску, короткі результати перевірок і
одним реченням поясни, чому `score_logic.py` не повинен читати `input()`.

## Критерії уроку

- логіка компонента та точка запуску розміщені окремо;
- імпорт і потік даних зрозумілі;
- програма запускається та зберігає попередню поведінку;
- помилковий випадок не маскується як успішний результат.
