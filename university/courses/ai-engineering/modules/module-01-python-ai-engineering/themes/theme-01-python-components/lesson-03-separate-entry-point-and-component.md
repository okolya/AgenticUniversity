# Урок 3. Відокремлюємо модуль від точки запуску

## Мета уроку

Після уроку студент уміє розмістити логіку повторного використання в одному
Python-модулі, а запуск із командного рядка — в іншому.

## Новий результат

Новий результат — імпорт і межа файлів: компонент можна використати іншим
Python-кодом без запуску програми через командний рядок.

## Практичне завдання

Розділи локальний компонент на два файли в одній папці:

- `delivery_logic.py` — `calculate_delivery_fee()` і
  `format_delivery_quote()`;
- `delivery_app.py` — `parse_arguments()`, `main()` та перевірка
  `if __name__ == "__main__":`.

`delivery_logic.py` не повинен викликати `input()`, читати аргументи командного
рядка або друкувати. `delivery_app.py` має імпортувати логіку й залишатися
єдиною точкою запуску програми.

Запусти:

```bash
python3 delivery_app.py 2 10
```

Перевір також один прямий імпорт `delivery_logic` без запуску `delivery_app`.
Приймаючий Lecturer перевірить запуск із заявленої команди та імпорт.

## Мінімальна здача

Передай `delivery_logic.py` і `delivery_app.py` через блок Artifact (передача файлів) у клієнті.
Потім поверни імена двох файлів, команду і короткі фактичні результати запуску та
прямого імпорту. Одне речення має пояснити, чому імпорт модуля не повинен
запускати програму з командного рядка. Локальні шляхи не замінюють передачу файлів.

## Критерії

- логіка повторного використання та точка запуску розділені файлами;
- імпорт не запускає поведінку командного запуску;
- потік даних між файлами явний;
- код зберігає поведінку, але не дублює логіку.
