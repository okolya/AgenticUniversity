# Урок 3. Відокремлюємо модуль від точки запуску

## Мета уроку

Після уроку студент уміє розмістити reusable-логіку в одному Python-модулі,
а запуск із командного рядка — в іншому.

## Новий результат

Новий `evidence delta` — імпорт і межа файлів: компонент можна використати
іншим Python-кодом без запуску CLI.

## Практичне завдання

Розділи `delivery_quote.py` на два файли в тій самій папці:

- `delivery_logic.py` — `calculate_delivery_fee()` і
  `format_delivery_quote()`;
- `delivery_app.py` — `parse_arguments()`, `main()` та перевірка
  `if __name__ == "__main__":`.

`delivery_logic.py` не повинен викликати `input()`, читати аргументи командного
рядка або друкувати. `delivery_app.py` має імпортувати логіку.

Запусти:

```bash
python3 homeworks/ai-engineering/2026.09/module-01/theme-01/delivery_app.py 2 10
```

Перевір також один прямий імпорт `delivery_logic` без запуску `delivery_app`.
Приймаючий Lecturer перевірить запуск із заявленої команди та імпорт.

## Мінімальна здача

Поверни шляхи двох файлів, команду і короткі фактичні результати запуску та
прямого імпорту. Одне речення має пояснити, чому імпорт модуля не повинен
запускати CLI.

## Критерії

- reusable-логіка та entry point розділені файлами;
- імпорт не запускає CLI-поведінку;
- потік даних між файлами явний;
- код зберігає поведінку, але не дублює логіку.
