# Theme 1 — Examinability contribution

**Contributor:** Examiner Profession, Engineering Faculty scope

## Purpose

Ensure that Theme 1 produces useful evidence for the later Module examination
without turning the Theme into an examination.

## Examination relevance

The Theme evidence can support Module Exit criteria concerning:

- readable components and clear function/data boundaries;
- explicit entry-point and reusable-code separation;
- ordinary, boundary, and failure behavior;
- controlled change, focused checks, and stated validation limits.

## Independence boundary

The Examiner does not examine the Student during Theme delivery, does not issue a
Theme verdict, and does not rewrite the Module Exit Contract. At Module exit,
the Dean Profession must hand the approved Module criteria and examination
scope to the Examiner Profession.
