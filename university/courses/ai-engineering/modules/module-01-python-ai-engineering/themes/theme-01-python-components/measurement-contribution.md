# Theme 1 — Measurement contribution

**Contributor:** Learning Analyst Profession, Engineering Faculty scope

## Purpose

Define what evidence would be observable if the Theme 1 criteria later require
independent measurement. This is a design contribution, not an assessment
verdict and not a learner-facing assessment artifact.

## Criterion map

- function responsibility: inspect named functions and compare the observed
  data flow with the Student's short explanation;
- explicit data boundary: inspect parameters, return values, and absence of
  hidden input/output in reusable logic;
- entry-point boundary: inspect separate files and run the declared command;
- behavior: run ordinary, boundary, and failure cases;
- controlled change: inspect the changed behavior and verify restoration;
- limits: ask one focused question about what the checks do not establish.

## Independence boundary

Lesson submissions are formative evidence owned by the assigned Lecturer. If
the Dean later needs independent Theme measurement, the Dean Profession must
issue a complete Assessment Request Contract before the Learning Analyst
builds or conducts an assessment. The Analyst does not decide
progression or Module placement.
