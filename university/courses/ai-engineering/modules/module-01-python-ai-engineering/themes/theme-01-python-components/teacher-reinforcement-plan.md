# Theme 1 — Teacher reinforcement plan

**Owner:** Teacher Profession, Engineering Faculty scope

## Purpose

Provide bounded consolidation only when the assigned Lecturer's Lesson evidence shows that the
Student can run the code but cannot yet explain or safely modify a function
boundary.

## Trigger

The assigned Lecturer may request this plan only for a concrete gap such as:

- mixed responsibilities remain in one function;
- the Student cannot trace a value from input to output;
- the Student cannot explain parameters, return values, or the entry point;
- the controlled change is completed mechanically but not explained.

## Support activity

The resolved Teacher Worker may use one short explanation, one small example, and one focused change
inside the existing Theme 1 criteria. The support does not add a Lesson, alter
the Theme outcome, or issue an independent mastery verdict.

## Evidence and stop

The Student returns the changed artifact and a short explanation. The Teacher
reports the observed gap and result to the Lecturer. The support stops after the one bounded
correction; a persistent or broader gap returns to Dean.

## Current status

Not invoked. Theme 1 delivery has not yet produced a concrete reinforcement
gap.
