# Урок 1. Визначаємо межі чистого компонента

## Мета уроку

Після уроку студент уміє перетворити вимогу на малий компонент із
відокремленими обчисленням і форматуванням. Цей урок не перевіряє повторно
введення, перетворення тексту чи обробку помилок Course Entry diagnostic.

## Новий результат

Новий `evidence delta` — функції компонента приймають уже підготовлені дані,
мають одну відповідальність і можуть бути викликані без термінала.

## Приклад

```python
def calculate_delivery_fee(weight_kg, distance_km):
    return 5 + weight_kg * 0.8 + distance_km * 0.02


def format_delivery_quote(weight_kg, distance_km, fee):
    return f"Delivery {weight_kg}kg/{distance_km}km: {fee:.2f}"
```

`calculate_delivery_fee()` обчислює значення, а `format_delivery_quote()`
перетворює готові дані на повідомлення. Жодна з них не викликає `input()` або
`print()`.

## Практичне завдання

Створи файл:

`homeworks/ai-engineering/2026.09/module-01/theme-01/delivery_quote.py`

Реалізуй:

- `calculate_delivery_fee(weight_kg, distance_km)` за формулою
  `5 + weight_kg * 0.8 + distance_km * 0.02`;
- `format_delivery_quote(weight_kg, distance_km, fee)` з форматом
  `Delivery <weight>kg/<distance>km: <fee з двома знаками>`;
- `main()`, який демонструє один виклик компонента.

Не додавай введення з термінала до двох функцій компонента.

Перевір запуском приклад `2` і `10`, для якого очікується:
`Delivery 2kg/10km: 6.80`.

## Мінімальна здача

Поверни шлях до файла, команду запуску та фактичний результат. Приймаючий
Lecturer перегляне й запустить код. За потреби він поставить одне питання:
яка функція може бути викликана без термінала і чому.

## Критерії

- кожна функція має одну основну відповідальність;
- компонент отримує дані параметрами й повертає результат;
- обчислення не залежить від `input()` або `print()`;
- потік даних зрозумілий.
