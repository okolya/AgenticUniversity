# Урок 1. Розділяємо відповідальність функцій

## Мета уроку

Після уроку студент уміє розділити невелику програму на функції з чіткими
обов'язками та пояснити, як дані проходять від введення до результату.

Цей урок не повторює базове читання Python. Він переводить уже перевірене
вміння запускати програму та читати помилки в уміння підтримувати зрозумілу
структуру коду.

## Нові слова

- **Функція** — іменована частина програми, яку можна викликати для виконання
  певної дії.
- **Відповідальність функції** — одна основна дія, за яку відповідає функція.
  Наприклад, одна функція перетворює текст на число, а інша визначає його
  категорію.
- **Точка запуску** — місце, з якого починається виконання програми. У
  невеликій Python-програмі це зазвичай `main()` та перевірка
  `if __name__ == "__main__":`.
- **Потік даних** — порядок, у якому значення переходять від однієї частини
  програми до іншої.
- **Поріг** — значення, з якого змінюється результат перевірки. У цьому
  завданні поріг `80` визначає перехід до мітки `ready`.
- **Контрольована зміна** — одна навмисна зміна в коді, після якої ми
  перевіряємо лише очікувану змінену поведінку, а потім повертаємо початкову
  вимогу.

## Приклад

Уявімо програму, яка отримує оцінку, перевіряє її межі та виводить короткий
результат. Зручно розділити її так:

```python
def parse_score(raw_score):
    score = int(raw_score)
    if score < 0 or score > 100:
        raise ValueError("score must be between 0 and 100")
    return score


def classify_score(score):
    if score >= 80:
        return "ready"
    return "keep practicing"


def format_report(score, label):
    return f"Score {score}: {label}"


def main():
    raw_score = input("Enter a score from 0 to 100: ")
    score = parse_score(raw_score)
    label = classify_score(score)
    print(format_report(score, label))


if __name__ == "__main__":
    main()
```

Тут потік даних такий:

1. `main()` отримує текст.
2. `parse_score()` перетворює текст на число та перевіряє межі.
3. `classify_score()` визначає категорію оцінки.
4. `format_report()` готує текст результату.
5. `main()` друкує результат.

Назви функцій показують їхню відповідальність. Якщо одна функція одночасно
читає введення, перевіряє межі, визначає категорію та друкує текст, її важче
перевіряти й змінювати.

## Практичне завдання

Створи файл:

`homeworks/ai-engineering/2026.09/module-01/theme-01/score_report.py`

Напиши програму для оцінки від `0` до `100`. Розділи її щонайменше на такі
функції:

- `parse_score(raw_score)` — перетворює введений текст на ціле число та
  відхиляє значення поза межами `0...100`;
- `classify_score(score)` — повертає точний рядок `ready` для оцінки від `80`
  і точний рядок `keep practicing` для меншої оцінки;
- `format_report(score, label)` — формує підсумковий рядок;
- `main()` — керує послідовністю введення, обробки та виведення.

Програма має запускатися командою:

```bash
python3 homeworks/ai-engineering/2026.09/module-01/theme-01/score_report.py
```

Перевір щонайменше такі випадки:

- `80` — `Score 80: ready`;
- `55` — `Score 55: keep practicing`;
- `110` — помилка про межі оцінки;
- `five` — помилка перетворення тексту на число.

Зроби одну контрольовану зміну: тимчасово зміни поріг `80` на `90`, перевір
оцінку `85`, а потім поверни програму до вимоги уроку.

## Мінімальна здача

Поверни:

- шлях до файла та команду запуску;
- короткий фактичний результат перевірених випадків;
- одним-двома реченнями поясни відповідальність `parse_score`,
  `classify_score`, `format_report` і `main`;
- результат контрольованої зміни порогу.

Не переписуй повний вивід термінала. Приймаючий працівник сам перегляне та
запустить файл і поставить одне коротке питання, якщо пояснення не покаже
розуміння потоку даних.

## Критерії уроку

- функції мають відокремлені основні відповідальності;
- потік даних між функціями відповідає опису;
- програма працює для звичайного та помилкових випадків;
- студент може пояснити структуру й безпечно виконати контрольовану зміну.
