# Урок 4. Підсумкова контрольна точка теми 1

## Мета уроку

Показати в одному невеликому компоненті, що студент уміє визначати
відповідальність функцій, передавати дані через межі та відокремлювати код
компонента від точки запуску.

Це останній урок теми 1. Після нього нові уроки в цій темі не створюються
автоматично.

## Завдання

Створи або заверш проєкт у папці:

`homeworks/ai-engineering/2026.09/module-01/theme-01/score-component/`

У ньому мають бути:

- `score_logic.py` із функціями обробки та формування результату;
- `score_app.py` із точкою запуску;
- за потреби короткий файл перевірок, але без зайвих залежностей.

Компонент має приймати оцінку від `0` до `100`, повертати зрозумілий результат
для звичайного значення та завершуватися визначеною помилкою для тексту й
значення поза межами.

## Обов'язкові перевірки

Перевір:

- звичайне значення `80`;
- значення нижче порогу, наприклад `55`;
- межі `0` і `100`;
- текстове значення `five`;
- значення `110`.

Зроби одну малу контрольовану зміну в компоненті, перевір її наслідок і
поверни код до початкової вимоги.

## Мінімальна здача теми

Поверни:

1. шляхи файлів і команду запуску;
2. коротку таблицю або список фактичних результатів п'яти перевірок;
3. короткий опис відповідальності основних функцій і потоку даних;
4. результат контрольованої зміни;
5. одне речення про те, що перевірки не доводять.

Не надсилай повні журнали термінала. Приймаючий працівник перегляне файли,
запустить програму, порівняє опис із поведінкою та поставить коротке питання
або попросить одну малу зміну, якщо цього потребує перевірка розуміння.

## Критерії завершення теми 1

Тема завершена, якщо студент:

- показує окремі й зрозумілі відповідальності функцій;
- передає дані через параметри та результати, а не через прихований стан;
- має окрему точку запуску й компонентний код;
- перевіряє звичайні, граничні та помилкові випадки;
- пояснює структуру та безпечно виконує контрольовану зміну.

Після перевірки викладач передає декану результати та невирішені питання.
Наступна тема відкривається лише окремим рішенням декана.
