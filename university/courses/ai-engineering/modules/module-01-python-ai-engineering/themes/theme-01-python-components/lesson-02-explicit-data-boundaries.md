# Урок 2. Передаємо дані через явні межі

## Мета уроку

Після уроку студент уміє передавати дані до функції через параметри та
отримувати результат через `return`, не ховаючи введення й виведення всередині
багаторазово використовуваної логіки.

## Що вже потрібно знати

Потрібно розуміти функцію, відповідальність функції та потік даних із Уроку 1.

## Нові слова

- **Параметр** — ім'я для значення, яке функція отримує під час виклику.
- **Результат функції** — значення, яке функція повертає через `return`.
- **Побічна дія** — зміна або дія поза самим обчисленням, наприклад читання
  `input()` або друкування через `print()`.
- **Явна межа даних** — правило, за яким функція отримує потрібні дані через
  параметри й повертає результат, а не шукає дані приховано.

## Приклад

Функція обчислення не повинна сама запитувати ціну:

```python
def calculate_total(quantity, price):
    return quantity * price


def main():
    quantity = int(input("Quantity: "))
    price = float(input("Price: "))
    total = calculate_total(quantity, price)
    print(f"Total: {total}")
```

`calculate_total()` можна перевірити окремо, бо всі її дані видно в параметрах,
а результат повертається явно. `main()` відповідає за взаємодію з терміналом.

## Практичне завдання

Створи файл:

`homeworks/ai-engineering/2026.09/module-01/theme-01/invoice_total.py`

Напиши програму, яка отримує кількість товарів і ціну одного товару та друкує
загальну суму. Розділи її щонайменше на такі функції:

- `parse_quantity(raw_quantity)` — перетворює кількість на ціле число та
  відхиляє значення, менші за `1`;
- `parse_price(raw_price)` — перетворює ціну на число та відхиляє від'ємне
  значення;
- `calculate_total(quantity, price)` — повертає добуток;
- `main()` — читає введення, викликає функції та друкує результат.

Перевір `2` і `12.50`, значення `0`, а також текст `many`. Програма має
запускатися командою:

```bash
python3 homeworks/ai-engineering/2026.09/module-01/theme-01/invoice_total.py
```

## Мінімальна здача

Поверни шлях і команду запуску, короткі фактичні результати трьох перевірок та
одне речення про те, чому функція `calculate_total()` не повинна викликати
`input()`.
Приймаючий працівник перегляне й запустить код.

## Критерії уроку

- функції, які можна повторно використовувати, отримують дані через
  параметри;
- результат обчислення повертається через `return`;
- введення та друкування зосереджені в `main()`;
- звичайний і помилкові випадки працюють передбачувано.
