# Correction Git

Create the branch and commit only for an approved material correction, then
create the linked pull request when the host capability exists. Resolve
technical conflicts according to the binding resolution; a new substantive
decision is a blocker.

Automatic merge is permitted only when the proposal is labeled
`ready-to-apply`, required checks pass, repository protection permits it, and
the host has explicitly authorized the operation.
