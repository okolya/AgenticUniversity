# Build assessment

Construct an independent assessment from success criteria, evidence
requirements, and assessment policy. The learner-facing artifact must pass the
`Instructional Assistant` pedagogical review before publication or delivery.

## Contract

Input must include the active Worker, artifact type and path, purpose,
applicable success criteria where relevant, learner-facing versus assessor-only
scope, policy/mode, and only the Student context required for the operation.
The input must come from a complete Dean Assessment Request Contract. Output is
returned to the calling Worker; the Skill does not assume the Worker's academic
authority and does not replace the required Assistant review.
