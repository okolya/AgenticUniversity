# Create lab

Create a practical lab inside an approved Course/Module/Theme/Lesson scope that
exercises explicit competencies and states allowed AI/tool usage. A Lab cannot
create a new Theme, Lesson slot, criterion, or progression decision.

For executable lab work, include a bounded run contract, required ordinary and
failure cases, and minimal evidence. The accepting Laboratory Specialist must
inspect and run the submitted artifact and use a focused understanding check;
the lab must not substitute a long report for working code.

## Contract

Input must include the active Worker, parent scope, bounded handoff or trigger,
purpose, applicable success criteria where relevant, policy/mode, and only the
Student context required for the operation. Output is returned to the calling
Worker; the Skill does not assume the Worker's academic authority.
