# Generate exercise

Create a focused exercise tied to explicit success criteria, current learning
context, and an approved parent Course/Module/Theme/Lesson scope. It cannot
add a Lesson slot or redefine the parent outcome.

For executable exercises, specify the target artifact, run command, required
cases, and compact evidence only. The accepting Worker must inspect and run
the code and check understanding; do not add program maps or long descriptions
unless a criterion explicitly requires them.

## Contract

Input must include the active Worker, parent scope and bounded slot, purpose,
applicable success criteria where relevant, policy/mode, and only the Student
context required for the operation. Output is returned to the calling Worker;
the Skill does not assume the Worker's academic authority.
