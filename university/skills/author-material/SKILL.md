# Author material

Create learning material for explicit goals and success criteria using current
context and applicable source rules. The material must belong to an explicit
Course/Module/Theme/Lesson parent scope and an approved bounded slot.

## Contract

Input must include the active Worker, parent Course/Module/Theme/Lesson scope,
approved slot or handoff, purpose, applicable success criteria where relevant,
policy/mode, and only the Student context required for the operation. Output is
returned to the calling Worker; the Skill does not assume the Worker's
academic authority, create a parent scope, add a Lesson slot, or change a
parent outcome.
