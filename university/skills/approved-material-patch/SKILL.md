# Approved material patch

Apply only the authorized learning MATERIALS, exact targets, and exact scope named by a completed
Instructional Assistant, Lecturer, and, when required, Dean resolution.
Policies, Skills, workflows, course framework, configuration, and other
service files are forbidden targets.

The operation does not approve, broaden, or publish a proposal. It must report
an explicit blocker when the target or authorization is missing.
