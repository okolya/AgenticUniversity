# Issue management

Handle issue search, read, creation, and stable academic labels only after the
Instructional Assistant has completed the applicable review and resolution
chain.

Input must include the approved proposal, source version, affected academic
scope, and permitted outcome. Do not include Student or named Worker
identities. Existing issues are searched before a new issue is created.
Duplicate, rejected, or unresolved proposals do not create new issues.
